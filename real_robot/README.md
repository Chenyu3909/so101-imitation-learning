# Real Robot

This folder is for scripts, configuration notes, evaluation utilities, and small reproducible assets related to the physical SO-101 system.

Suggested future contents:

- camera configuration
- training commands
- rollout commands
- evaluation script
- plots generated from `results.csv`
- calibration notes that do not contain private machine paths or credentials

Do not commit Hugging Face access tokens, API keys, raw cache directories, or large model checkpoints.
