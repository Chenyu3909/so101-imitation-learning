# Base Camera Mount

This folder contains my custom CAD design for the SO-101 base camera mount used in the dual-camera imitation-learning setup.

## Files

- `base_camera_mount.step` — editable CAD exchange model.
- `base_camera_mount.stl` — printable mesh export.

I designed this mount to rigidly position the external base camera for a consistent view of the robot workspace while collecting demonstrations and running ACT inference.

The SO-101 arm itself is existing open-source hardware; this camera mount is my own project-specific mechanical design.
